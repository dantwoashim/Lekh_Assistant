## Sources

- `syubraj/roman2nepali-transliteration` from Hugging Face parquet for word aliases.
- `Boredoom17/Nepali-Flow-Roman` from Hugging Face parquet for public Romanized social/casual rows.
- `Boredoom17/Nepali-Flow-Colloquial` from Hugging Face parquet for public mixed Nepali-English rows.
- Existing project seed aliases and phrases from `src/data/aliases/romanized-aliases.tsv` and `src/data/phrases/romanized-phrases.tsv`.
- Synthetic-silver generators for proofread perturbations, names, mixed-policy stress cases, phrase coverage, and next-context coverage.

## Review Tiers

- `auto-reviewed-open-license`: machine-filtered open dataset row; not human-reviewed gold.
- `auto-reviewed-token-aligned`: generated by aligning high-confidence token aliases; not human-reviewed gold.
- `pii-screened-open-social`: public/social row with automated privacy and quality filters; still requires human privacy review before redistribution.
- `synthetic-silver`: generated from deterministic rules/templates for coverage and stress testing; promote only after human review.
- `project-internal-seed`: project-curated seed row; useful for bootstrapping but not frequency evidence.

## Git Packaging Note

The full generated and curated corpora remain available in the local workspace, but the multi-hundred-megabyte JSONL outputs are intentionally excluded from normal Git push because they would bloat remote history and exceed practical GitHub packaging limits. The pushed repo includes the corpus builder/curation/validation scripts, source registry, annotation guide, review scaffolding, reports, and runtime packs needed to reproduce the local data build with:

```sh
npm run corpus:keyboard
npm run corpus:keyboard:validate
```

## Important Use Guidance

This corpus is ready for engine training, candidate generation, ranking experiments, helper suggestion mining, proofread stress testing, and blind evaluation scaffolding. Rows are review-tiered; do not claim human-reviewed 99%+ accuracy from this corpus until the gold-review promotion workflow has reviewed representative samples and the frozen test set has measured the actual engine.
